# 《人生切割术》Severance —— 文本版人物关系图

Apple TV+ 2022–2025，已播两季 19 集（第一季 2022-02-18 至 2022-04-08，共 9 集；第二季 2025-01-17 至 2025-03-21，共 10 集），第三季已续订，尚未播出。
核心是一句话：一家叫 Lumon 的公司用“切割手术”把员工的记忆一分为二——上班的 innie 只记得工作，下班的 outie 只记得生活，两个人共用一具身体，却互不知情。
图例：—— 夫妻 / 家人　　→ 上下级 / 效忠　　× 对手　　～ 恋人　　◇ 交易 / 利用　　† 杀害 / 致死　　≡ 同一个人的两面

## 一、几条主线

```
切割与 MDR 工作线：Mark、Helly、Dylan、Irving 在被切割楼层做“宏观数据精炼”，
       每天对着数字分类，根本不知道自己在炼什么 —— 第二季揭晓：每完成一份文件，
       就为 Gemma 造出一个新的人格。
Mark 寻妻线：outie Mark 以为妻子 Gemma 车祸去世，才来 Lumon 上班麻痹自己 ——
       第一季末发现健康顾问凯西小姐就是 Gemma —— 第二季接受融合手术，决心把她救出来。
Helly 身份线：反抗最激烈的 Helly，outie 竟是 Lumon CEO 之女 Helena ——
       第二季 Helena 亲自冒充 Helly 上班，直到野外拓展时被 Irving 识破、Irving 因此被开除。
Lumon 阴谋线：Cobel 被解雇后倒戈，揭开自己才是切割手术的发明者、Cold Harbor 是
       Gemma 的最后一个测试人格 —— 完成后 Lumon 会取出 Gemma 脑中的芯片，她也将死去。
```

## 八、核心关系线（一句话版）

1. Mark innie ≡ Mark outie：同一个人，两个互不知情的人生；第二季融合手术让两人开始共享记忆。
2. Mark —— Gemma：夫妻；outie 以为妻子车祸去世，innie 在楼里把她当成健康顾问凯西小姐。
3. Mark innie ～ Helly：MDR 同事，相爱；终集 innie Mark 为她放弃离开 Lumon。
4. Helly ≡ Helena：同一个人；Helena 是 Lumon CEO 之女，第二季曾冒充 Helly 上班。
5. Helena —— Jame：父女；Jame 是 Lumon 的现任 CEO。
6. Irving ～ Burt：恋人；Irving 被开除后，outie Burt 开车送他离开基尔镇。
7. Dylan innie ～ Gretchen：innie 在探访中爱上了 outie 的妻子，夫妻关系因此出现裂痕。
8. Cobel → Mark：表面是楼层主管与下属、邻居 Selvig 太太；第二季倒戈，揭开 Cold Harbor 的真相。
9. Cobel × Lumon：她发明了切割手术，却被公司夺走功劳、扫地出门。
10. Milchick → MDR：楼层主管与下属；终集被员工以“绩效评估”反制围堵。
11. Miss Huang → Milchick：上下级；Wintertide Fellowship 一结束，她就被送走。
12. Drummond → Lumon：公司的打手；终集被切换回 outie 的 Mark 误用电击枪杀死。
13. Devon —— Mark：兄妹；Devon 与 Cobel 一起帮 Mark 制定营救 Gemma 的计划。
14. Devon —— Ricken：夫妻；Ricken 的自助书成了 innie 们的精神食粮。
15. Petey → Mark：前后任 MDR 主管；Petey 的融合与死亡，引出了 Mark 的全部调查。
16. Reghabi → Mark / Petey：融合手术的执行者，Mark 第二季融合手术的操刀人。
17. Lorne → Mark：山羊部门主管；终集用电击枪帮 Mark 挡住 Drummond，救了他的命。

## 九、结局（第二季第十集《Cold Harbor》，2025-03-21）

- Cobel 揭开真相：Mark 每完成一份 MDR 文件，就为 Gemma 造出一个新的人格；Cold Harbor 是最后一个，完成后 Lumon 会取出 Gemma 脑中的芯片，她也将死去。
- innie Mark 完成 Cold Harbor，挟持 Drummond 下到健康楼层；切换回 outie 的 Mark 误用电击枪杀死 Drummond，救出 Gemma，两人在电梯里重逢。
- 回到被切割楼层，innie Mark 把 Gemma 送到出口楼梯口：她跨过去变回 Gemma，独自逃出 Lumon；而 innie Mark 选择不跟她走，转身拉起 Helly 的手，两人跑进响着警报的走廊深处。
- 其他收尾：Irving 的 innie 已被开除，outie Burt 开车送他离开；Miss Huang 乘巴士离开；Milchick 被 MDR 员工围堵；第三季已续订，尚未播出。
