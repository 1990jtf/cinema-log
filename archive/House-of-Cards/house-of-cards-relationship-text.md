# 《纸牌屋》House of Cards —— 文本版人物关系图

Netflix 2013–2018，六季 73 集。改编自英国同名剧集与小说的政治惊悚剧。
核心是一句话：一对野心勃勃的夫妻，用阴谋、背叛与谋杀，一步步爬上白宫之巅。
图例：—— 夫妻 / 搭档　　→ 上下级 / 效忠　　× 对手　　～ 恋人　　◇ 交易 / 利用　　† 杀害 / 致死

---

## 一、几条主线

```
夺权线：Frank 是众议院多数党党鞭，帮 Walker 当选总统却没拿到承诺的国务卿 ——
       策动 Russo 州长竞选再亲手毁掉他 —— 逼副总统 Matthews 辞职，自己接任副总统 ——
       逼 Walker 辞职，第二季末成为第 46 任总统 —— 第四季击败 Conway 赢得大选
白宫斗争线：第三季 Frank 与 Claire 的婚姻危机 —— 第四季 Frank 遇刺受伤 —— 第五季 Frank
       辞职保 Claire 接任总统 —— 第六季 Frank 已死，Claire 独自执政，对抗 Shepherd 家族
媒体线：Zoe 拿 Frank 的内幕写独家，越挖越深 —— 第二季开场被 Frank 推下地铁 ——
       Hammerschmidt 接过调查，第五季发表长篇报道，成为压垮 Frank 的最后一根稻草 ——
       第六季他继续追查 Claire
商界线：Tusk 是 Walker 的金主，与 Frank 结盟后反目 —— Remy 在说客、幕僚长与 Conway
       阵营之间反复横跳 —— 第六季 Shepherd 家族以工业帝国为后盾，与白宫正面博弈
```

## 二、Underwood 夫妇与核心圈

```
Frank Underwood（众议院多数党党鞭 → 副总统 → 第 46 任总统）
        —— Claire Underwood（妻子，第一夫人 → 副总统 → 第 47 任总统）
        │
        ├─ Doug Stamper（幕僚长兼心腹，“清道夫”，替 Frank 办一切脏活）
        └─ Freddy Hayes（烤肉店老板，Frank 的老友，白宫外唯一的避风港）

Frank 与 Claire：政治上的夫妻档，互相成就也互相算计。第四季 Claire 一度出走竞选众议员，
第五季又回到 Frank 身边当副总统；Frank 辞职后 Claire 接任总统，第六季她独自坐在王座上。
```

## 三、白宫与政府

```
Garrett Walker（第 45 任总统）
        │
        ├─ Linda Vasquez（白宫幕僚长，识破 Frank 却斗不过他，第二季辞职）
        ├─ Catherine Durant（国务卿，Frank 的盟友与棋子，第五季反水作证）
        ├─ Jackie Sharp（众议院多数党党鞭，第四季参加总统初选挑战 Frank）
        ├─ Peter Russo（宾州众议员，被 Frank 捧起又毁掉，第一季身亡）
        └─ Mark Usher（政治操盘手，第五季助 Frank 连任，第六季任 Claire 的副总统）

Frank 的升迁链：党鞭（S1）→ 副总统（S2）→ 总统（S2 末 Walker 辞职）→ 赢得大选（S4）
→ 辞职（S5）→ Claire 接任总统（S5 末至今）。
```

## 四、媒体与记者

```
《华盛顿先驱报》（The Washington Herald）
        │
        ├─ Zoe Barnes（记者，与 Frank 交易内幕，第二季开场被推下地铁身亡）
        ├─ Tom Hammerschmidt（主编，第五季发表调查报道，扳倒 Frank）
        ├─ Janine Skorsky（记者，Zoe 的同事，协助 Hammerschmidt 查案）
        └─ Tom Yates（作家，为 Frank 写传，与 Claire 有染，第五季遇害）

媒体是 Frank 的武器，也是他的掘墓人：Zoe 帮他放料上位，Hammerschmidt 的调查最终把他拉下马。
```

## 七、核心关系线（一句话版）

1. Frank —— Claire：政治夫妻档，互相成就也互相算计；Frank 死后 Claire 独自坐上王座。
2. Frank → Walker：Frank 帮 Walker 当选总统，Walker 却食言不给国务卿，Frank 从此设局复仇。
3. Frank → Russo：Frank 把 Russo 推上州长候选人，又亲手毁掉他，Russo 第一季身亡。
4. Frank → Zoe：Zoe 拿 Frank 的内幕写独家，越挖越深，第二季开场被 Frank 推下地铁。
5. Frank → Doug：Doug 是 Frank 的“清道夫”，替他杀人、顶罪、善后，忠诚到偏执。
6. Frank × Tusk：从盟友到死敌，Tusk 第二季因洗钱被捕，Frank 顺势扫清障碍。
7. Frank × Durant：国务卿是 Frank 的棋子，第五季反水，在国会作证指控 Underwood 夫妇。
8. Frank × Sharp：Sharp 第四季参加总统初选，正面挑战 Frank 的提名。
9. Frank × Hammerschmidt：Hammerschmidt 第五季的调查报道，是压垮 Frank 的最后一根稻草。
10. Claire × Yates：Yates 为 Frank 写传，与 Claire 有染，第五季遇害身亡。
11. Claire → LeAnn：LeAnn 是 Claire 的亲信与操盘手，第五季死于车祸。
12. Claire × Jane Davis：Jane 是手握各国黑料的中间人，第六季与 Claire 从合作走向反目。
13. Claire × Annette：Shepherd 家族掌门先是 Claire 的盟友，第六季变为白宫最大的对手。
14. Walker → Vasquez：Vasquez 是 Walker 的幕僚长，识破 Frank 的布局却无力阻止，第二季辞职。
15. Frank → Freddy：Freddy 的烤肉店是 Frank 白宫之外唯一的避风港，两人亦友亦主仆。
16. Remy ◇ 各方：顶级说客在 Tusk、Frank 与 Conway 之间反复横跳，谁给的价高就为谁服务。
17. Doug † Frank：第六季终集揭晓，Doug 给 Frank 的肝病药下了致命剂量，只为“保护 Frank 的遗产”。

---

## 八、结局（第六季第八集《第 73 章》）

- 第六季开场 Frank 已经死了：Claire 对外称他死于肝病，实际上死因成谜。
- Claire 以第 47 任总统的身份独自执政，一边与 Shepherd 家族、Jane Davis 明争暗斗，一边应付 Hammerschmidt 的调查和国会传票。
- 终集里，Doug 承认是他给 Frank 的肝病药下了致命剂量，只为“保护 Frank 的遗产”；Claire 在椭圆形办公室亲手刺死了 Doug。
- 最后一个镜头：Claire 怀着 Frank 的孩子，对着镜头说：该我了（My turn）。
