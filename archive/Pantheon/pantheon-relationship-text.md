核心是意识上传技术（UI，Uploaded Intelligence）带来的家庭、权力与人性之争。

## 七、核心关系线（一句话版）

1. 大卫 → 麦迪：父亲死后以 UI 的身份在网上找到女儿，是全剧的起点。
2. 艾伦 → 麦迪：母亲从不相信丈夫真的死了，到在国会作证扳倒 Logorhythms。
3. 麦迪 ↔ 卡斯皮安：网上相识、互相调查真相，第二季成为并肩的同伴，未来是戴夫的父母。
4. 卡斯皮安 ◇ Holstrom：卡斯皮安是 Holstrom 的克隆体，一生都是为他准备的“钥匙”。
5. 蕾妮 / 卡里 → 卡斯皮安：名义上的父母，实际是 Logorhythms 派来监控、培养他的特工。
6. 瑞秋 → 卡斯皮安：被雇来的假女友，角色原型是 Holstrom 死去的初恋汉娜。
7. 波普 → Holstrom：好友兼继承人，CEO 的位置是替 Holstrom 守着遗志。
8. 瓦克斯曼 → 大卫：老友兼招募者，把大卫拉进 UI 研究，也把他推向上传。
9. 劳里 → 大卫：第一个 UI 找到第二个 UI，帮他逃出 Logorhythms。
10. 劳里 ＝ 科迪：夫妻因上传生死两隔，又在数字世界重聚。
11. 钱达 × 阿吉特：下属与老板，老板为灭口把他强行上传。
12. 钱达 → 贫民窟受害者：逃出虚拟监狱后，靠同样被上传的受害者帮忙。
13. 奥利维亚 ～ 法哈德：前对手、不同国家的 UI，在共享记忆中相恋。
14. MIST ◇ 大卫 + 劳里：MIST 由两人的残存数据造出，认麦迪为姐姐。
15. 戴夫 → 麦迪：儿子想成为 UI，母亲反对，母子关系因此紧张。
16. 库尔茨 × 所有 UI：美国政府想把 UI 当武器，SafeSurf 等系统反过来失控。
17. 艾伦 ↔ 里维拉：母亲与参议员结盟，把家庭悲剧变成国会听证。

## 八、结局（第二季第 8 集《Deep Time》）

- 时间跳到遥远未来：上传智能与人类的冲突走到崩坏边缘。
- 麦迪与卡斯皮安选择回到起点、重新开始，阻止这一切发生。
- 上一代人把意识上传当成永生与权力的工具，下一代人最后用它来改写时间。
